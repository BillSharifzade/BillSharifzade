# Marks used in the Stack rows

The rows in `assets/stack-*.svg` are built by `scripts/stack.mjs` from the tiles in this
directory, so the README does not depend on a third-party icon API.

| Path | Source | Terms |
| --- | --- | --- |
| `skillicons/*.svg` | [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons) | MIT |
| `logos/opengl.svg`, `logos/gentoo.svg` | [devicons/devicon](https://github.com/devicons/devicon) | MIT |
| `logos/vulkan.svg` | [devicons/devicon](https://github.com/devicons/devicon), split into two paths so the wordmark can be white on a dark tile | MIT |
| `logos/tokio.svg` | [tokio-rs/website](https://github.com/tokio-rs/website) | Tokio project mark |
| `logos/ratatui.svg` | [ratatui/ratatui](https://github.com/ratatui/ratatui) | Ratatui project mark |
| `logos/hyper.svg` | [hyperium/hyperium.github.io](https://github.com/hyperium/hyperium.github.io) | hyper project mark |
| `logos/chi.svg` | [go-chi/chi](https://github.com/go-chi/chi) | chi project mark |
| `logos/numpy.svg` | [numpy/numpy](https://github.com/numpy/numpy) `branding/logo/logomark` | NumPy logo guidelines |
| `logos/pandas.svg` | [pandas-dev/pandas](https://github.com/pandas-dev/pandas) `pandas_mark_white.svg` | pandas brand guidelines |
| `logos/systemd.svg` | [systemd/brand.systemd.io](https://github.com/systemd/brand.systemd.io) `systemd-logomark-dark.svg` | systemd brand guidelines |
| `wordmarks/*.svg` | generated by `scripts/wordmark-tile.py` from Noto Sans Bold / Noto Sans Mono Bold | SIL OFL 1.1 (fonts); tiles are original |

Project names and logos belong to their respective projects and appear here only to
identify the tools they stand for.
